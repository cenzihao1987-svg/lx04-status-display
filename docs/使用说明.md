# 使用说明

## 目录

- `vendor/mibe/` — 上游开源项目 [yihong0618/mibe](https://github.com/yihong0618/mibe)，负责监听 Codex 会话日志和小爱音箱播报。本项目的适配改动记录在 `vendor/mibe.patch`。
- `bridge/run.py` — 我们写的：挂在 mibe 的事件流上，把状态输出成网页和接口
- `display/index.html` — 800×480 状态屏页面
- `scripts/start.sh` — 启动脚本
- `scripts/install-agent.sh` — 装成开机自启（见下方「开机自启」）
- `scripts/adb-bridge.py` — 在音箱本机转发到 Mac，不再依赖 Mac 的 DHCP 地址
- `scripts/speak.sh` — 跑着的时候开关播报

## 现在就能跑：状态屏

```bash
cd ~/lx04-status-display
./scripts/start.sh
```

启动后会打印 Mac 自己可访问的地址：

```
状态屏  http://192.168.x.x:8477/
接口    http://192.168.x.x:8477/api/status
```

在 Mac 浏览器打开第一个地址就能看到效果。LX04 不使用这个会变化的地址；装好下方的开机自启后，它固定访问：

```
http://127.0.0.1:8477/
```

这个 `127.0.0.1` 指音箱自己。Mac 通过无线 ADB 在音箱上维护一个本机代理，把它转到状态服务，所以 Mac 的 DHCP 地址变化不会影响音箱。

**要停止**：在终端按 `Control + C`。

**播报默认是关的。** 这条命令只跑状态屏，不会碰你的小米账号，也不会让音箱出声。要开播报见下面 Phase A。

### 开机自启

上面那条命令跑在终端里，关掉终端或者重启 Mac 就没了。要让它一直在：

```bash
./scripts/install-agent.sh
```

装完之后：登录 macOS 自动起、进程意外退出自动拉起、重启 Mac 不用管。

| 干什么 | 命令 |
| --- | --- |
| 看状态屏日志 | `tail -f ~/Library/Logs/lx04-status.log` |
| 看 ADB 本机代理日志 | `tail -f ~/Library/Logs/lx04-adb-bridge.log` |
| 改了 `bridge/run.py` 后重启 | `launchctl kickstart -k gui/$(id -u)/com.gerry.lx04-status` |
| 卸载 | 同时卸载 `com.gerry.lx04-status` 与 `com.gerry.lx04-adb-bridge` 两个 LaunchAgent |

两点要知道：

- **`KeepAlive` 是无条件的**，手动 `kill` 也会被拉起来。要真停必须走上面的卸载命令。
- **自启只跑状态屏，不播报**。播报要小米账号（`MI_USER` / `MI_PASS`），而 LaunchAgent 读不到你 shell 里的环境变量。要播报就手动跑 `./scripts/start.sh --speak`。
- ADB 本机代理每 10 秒自检一次。音箱或 Mac 换到新 DHCP 地址后，会优先尝试上次地址，失败才扫描当前 `/24` 网段确认 LX04；不用再到音箱上改网址。

#### 指定 Mac 的局域网地址（可选）

默认自动读取 Mac 的 Wi-Fi 地址（`en0`）。如果 Wi-Fi 使用其他接口，或自动识别不正确，可在 `~/Library/Application Support/lx04-status/adb-endpoint.json` 中设置 Mac 的局域网 IPv4。文件不存在时，先创建父目录和这个 JSON 文件；若文件已存在，只需增加 `mac_ip` 字段并保留其他字段：

```json
{"mac_ip":"192.168.1.23"}
```

把示例地址换成 Mac 当前的局域网地址。代理会保留这个设置，并继续自动发现音箱地址。

### 状态怎么看

| 显示 | 颜色 | 含义 |
| --- | --- | --- |
| Ready | 蓝 | 没有进行中的任务 |
| Working | 琥珀（呼吸） | Codex 正在干活 |
| **Your Turn** | **紫（快闪）** | **Codex 停下来等你**——在问你问题，或请求授权。下方显示问题内容 |
| Done | 绿 | 任务完成，下方显示结果摘要和耗时 |
| Stopped | 石板灰 | 任务被你中断，或超过 15 分钟没动静 |
| Offline | 深灰 | 连不上 Mac（连续三次失败才切，避免闪烁） |

Your Turn 是这一版新增的，也是最该看的一个状态。Codex 停下来等你时，屏幕会亮紫色并把问题显示出来，你不用走回电脑前才发现它早就停了。

底部额度条按用量变色：70% 以下灰、70–90% 琥珀、90% 以上红。读不到额度时显示「额度暂不可用」，不显示猜测值。

### 数据从哪来

读 `~/.codex/sessions/` 下的会话日志。不需要装 Codex CLI，不需要连 App Server，Codex 正常用就有日志。

## Phase A：打开播报

播报默认关闭，必须显式加 `--speak` 才会开。配了账号也不会自己开。

1. 建一个只有你能读的凭证文件：

   ```bash
   touch ~/.mibe.env && chmod 600 ~/.mibe.env
   ```

2. 用任意编辑器填进去（`MI_DID` 先留空，下一步会告诉你填什么）：

   ```bash
   export MI_USER="你的小米账号"
   export MI_PASS="你的小米密码"
   export MI_DID=""
   ```

3. 加载凭证并列出你的音箱：

   ```bash
   source ~/.mibe.env
   cd ~/lx04-status-display/vendor/mibe
   .venv/bin/python mibe.py login
   ```

   会打印设备列表。找到 LX04 那一行，把它的 `miotDID` 填回 `~/.mibe.env` 的 `MI_DID`。

4. 重新加载并启动，这次加 `--speak`：

   ```bash
   source ~/.mibe.env
   cd ~/lx04-status-display && ./scripts/start.sh --speak
   ```

   启动信息显示「状态屏 + 播报」就说明开了。

### 跑着的时候开关播报

不用停服务。两种方式：

- **屏幕上点**：状态屏右上角有个「播报 开 / 播报 关」，点一下切换
- **命令行**：`./scripts/speak.sh off`，要开回来 `./scripts/speak.sh on`

关掉是立刻生效的：不再出声，音箱音量也会还给你（任务进行中 mibe 会把音量压到 0，关播报时会恢复，不会留个哑音箱给你）。

**没加 `--speak` 启动的话，右上角不会有这个开关，命令也会报错**——那次启动根本没登录小米，运行时也开不出来。这就是「默认关闭」：不给账号就不可能出声。

**彻底关掉**：Control + C 停掉，去掉 `--speak` 重新跑。

**通过标准**：Codex 开始任务时音箱说「codex启动」，结束时说「codex完成」，停下来问你时说「codex需要你确认」加问题内容。

**没通过怎么办**：

- 登录失败 → 账号密码不对，或小米要求验证码，重试
- 登录成功但没听到 → `MI_DID` 没指向 LX04，重跑第 3 步核对
- 播报内容想改 → 复制 `vendor/mibe/config.toml.example` 成 `vendor/mibe/config.toml` 改文案

## 我们改了 mibe 什么

本项目用 `vendor/mibe.patch` 保存对上游代码的适配。查看当前安装版本的具体改动：

```bash
cd ~/lx04-status-display/vendor/mibe && git diff
```

1. **加状态屏挂载点** — 让 `bridge/run.py` 能拿到事件流，mibe 原有播报逻辑不受影响
2. **加 `--no-speaker`** — 没配小米账号时也能只跑状态屏
3. **加运行时静音开关** — `muted` 一个标记位，出声和改音量两处都看它，播报开关就是切它
4. **兼容 `request_user_input_async`** — Codex 新出的提问变体，mibe 原来精确匹配旧名字会漏掉
5. **兼容 `title` 字段** — 同上，新变体用 `title` 存问题，mibe 原来只找 `question`/`header`
6. **降低常驻扫描开销** — 一秒轮询会话日志，文件大小未变化时跳过打开和读取

更新上游时先备份 `vendor/mibe.patch`；若补丁冲突，按上面的适配项重新应用。

## 远程调试音箱（不用跑到它跟前）

音箱的无线 adb 是开着的，Mac 上装了 `adb` 之后可以直接连，**不用插线**。

```bash
LX04_IP="192.168.1.50" # 替换成音箱当前的局域网 IPv4
adb connect "$LX04_IP:5555"
```

音箱地址会随路由器分配变化。可以查看路由器后台，或按当前 Wi-Fi 网段扫描，例如：`nmap -p 5555 192.168.1.0/24`。扫描网段要替换成你的局域网网段。

连上后，下面这些命令都用 `$LX04_IP` 指定目标，避免误操作其他已连接设备：

| 想干什么 | 命令 |
|---|---|
| 看屏幕现在什么样 | `adb -s "$LX04_IP:5555" shell screencap -p /sdcard/s.png && adb -s "$LX04_IP:5555" pull /sdcard/s.png` |
| 录一段动效 | `adb -s "$LX04_IP:5555" shell screenrecord --time-limit 10 /sdcard/r.mp4` |
| 模拟左滑（测翻页） | `adb -s "$LX04_IP:5555" shell input swipe 700 240 100 240 300` |
| 量掉帧 | `adb -s "$LX04_IP:5555" shell dumpsys gfxinfo mark.via.gp framestats` |
| 看页面的 console.log | `adb -s "$LX04_IP:5555" logcat \| grep chromium` |
| 直接打开状态屏 | `adb -s "$LX04_IP:5555" shell am start -a android.intent.action.VIEW -d "http://127.0.0.1:8477/" -p mark.via.gp` |

**录屏和帧率这两条最值钱**：动效和卡顿靠截图和肉眼说不清楚，这两个直接给答案。

> 顺带一提，无线 adb 默认开着意味着同一个 WiFi 下任何人都能连进来装东西。自己家网络问题不大，去别处连公共 WiFi 时值得想一下。

## 米家为什么被禁用了

刷完机之后设备会反复弹「米家已经停止运行」。抓日志看到的原因：

```
java.lang.OutOfMemoryError: Failed to allocate a 63968656 byte allocation
    at okhttp3.ResponseBody.string()
    at com.xiaomi.smarthome.core.network.api.SmartHomeRc4Api$3.onResponse()
```

米家的接口收到一个 **61MB 的响应体**，想一次性读成字符串。这台机器堆上限 128MB，当时可用只剩 6MB，直接 OOM。每次崩溃申请的字节数几乎一样，说明它在反复重试同一个请求，崩了又试、试了又崩。

崩的是后台网络线程，主界面不受影响，所以「点图标还能打开」。但**崩溃弹窗是系统级的，会盖住全屏浏览器**，把状态屏挡掉——这才是必须处理它的原因。顺带它每次都先要 61MB 内存，这台机器总共才 1GB。

这台设备只当状态屏用，米家一点用不上，所以禁掉了：

```bash
adb -s "$LX04_IP:5555" shell pm disable-user --user 0 com.xiaomi.smarthome
```

**可逆**，想要回来就把 `disable-user` 换成 `enable`，不动系统分区、不需要 root。

禁用后桌面上的米家图标还会留一阵（launcher 缓存），点了没反应，重启一次就没了。

## 屏幕显示不对了

**只露出左上角一块、字特别大** —— viewport 被锁死了。这块屏物理 800x480，但在浏览器眼里只有 534x320（density 240 导致 dpr=1.5），页面按 800 布局又锁 `initial-scale=1`，就只能露出 67%。

`display/index.html` 里那行 viewport **不能加 `initial-scale`**，加了就会复现。详见 `AGENTS.md` 的「设备硬约束」。

**页面没铺满、四周有黑边** —— 检查 Via 是不是在「电脑模式」。那个模式会忽略页面的 viewport，用自己的一套算宽度。

**双指缩放没反应** —— 这是故意的。`touch-action: pan-y` 把横滑留给页面翻页、竖滑留给浏览器收控制条，代价是禁掉了双指缩放。显示出问题时手势救不回来，得靠切模式或者 adb。

## 安全

- 小米账号密码放 `~/.mibe.env`，权限 600，不在项目里，不会被提交
- 登录凭证缓存在 `~/.mi.token`，同样不在项目里
- 不要把账号密码贴进项目任何文件

# LX04 刷机手册

带着这份去 Windows 电脑前，照着做。

---

## 一条红线

> **点了 FlashTool 的下载按钮之后，不要碰 USB 线，等它跑完。**

教程评论区变砖的那位就是中途拔的线，提示「软件下载不完整」。别的都能重来，这个不能。

---

## 第一步：在 Mac 上下载（现在做）

教程：https://post.smzdm.com/p/akk3k89r/
固件在评论区置顶的百度网盘，**提取码 `7y46`**

三个文件夹**都要下**：

| 文件夹 | 用途 |
|---|---|
| 第三方系统固件（SP5.5） | 要刷的东西 |
| **恢复官方系统固件** | **刷坏了救命用的，别嫌麻烦** |
| 第三方系统需要安装的 app | 教程配的 app，可选 |

解压后放进来：

```
刷机/固件/第三方SP5.5/     ← 第三方固件解压到这里
刷机/固件/恢复官方/        ← 恢复固件解压到这里
```

## 第二步：检查固件完整（现在做）

```bash
cd ~/小米音箱改造
python3 刷机/check.py
```

它会读固件里的分区表，逐个核对镜像文件在不在、大小对不对。**看到「可以刷」再往下走。**

看到 ❌ 就重新下载，别刷。SP Flash Tool 自己不检查这个，刷到一半发现文件不全就是砖。

## 第三步：准备硬件

- **数据线，至少 3 条** ← 这是最大的坑。评论区有人「试了十几条都不行」，作者说 OPPO 原厂线可以
- 音箱本体
- 把 `刷机/` 整个文件夹拷到 U 盘

---

## 第四步：在 Windows 上刷

1. **关掉杀毒软件和安全卫士**（会拦驱动安装）
2. 进 `SP5.5/driver/`，双击 `mediatek-drivers-install` 装驱动
3. USB 连音箱，**听到电脑提示音**才算连上。没声音就换线，换到有为止
4. 设备管理器里确认能看到 LX04
5. 找到 `FlashTool.exe`，**右键 → 以管理员身份运行**
6. 下载模式选 **「固件升级」**
7. 点「下载」按钮
8. **拔插一下音箱**，然后等 2-3 分钟 —— **这期间别碰线**
9. 出现下载完成弹窗
10. 再拔插一下音箱，等开机

**报 `STATUS_PROTOCOL_ERR(0xC0010005)`** = 驱动没认上。重装驱动，或者换线。

---

## 第五步：刷完之后（顺序别换）

### 1. 先喊一声「小爱同学」

**这一步必须在装任何东西之前做。**

评论区有一例报告刷完不能唤醒，多数人说正常。我们的语音播报功能完全依赖它。

- 能唤醒 → 播报功能保住了
- 不能唤醒 → 记下来，别急着折腾，回来再说

先测，你才知道是刷机搞坏的还是后面配置的问题。

### 2. 开 USB 调试

设置 → 系统 → **连点版本号** 直到提示打开开发者选项 → 返回进开发者选项 → 打开 **USB 调试** → 连接方式选 **MTP**

### 3. 装浏览器（趁人和电脑都在）

**记下屏幕上显示的 Android 版本号**，这决定装哪个：

| Android 版本 | 装这个 |
|---|---|
| 6.0 及以上 | **Fully Kiosk Browser** — 自动全屏、屏幕常亮、断线重连、开机自启 |
| 低于 6.0 | **Via 浏览器** — 1MB 出头，老系统能跑，全屏要手动设 |

装法：电脑上打开 LX04 的存储，把 APK 拷到 `download` 文件夹，然后在音箱里 设置 → 存储 → 文件 → download，双击安装。

> 忘了装也没关系，回 Mac 上用 adb 装也行，只是要多几步。

---

## 第六步：回家，打开状态屏

Mac 上先把服务跑起来：

```bash
cd ~/小米音箱改造
./scripts/start.sh
```

它会打印地址，长这样：

```
状态屏  http://192.168.1.100:8477/
```

在 LX04 的浏览器里输入这个地址，全屏。**完成。**

> 地址里的 IP 会变（换网络、路由器重新分配）。变了就重跑一次 `start.sh` 看新地址。

---

## 出问题了

- **刷成砖** → 用 `刷机/固件/恢复官方/` 里的固件，同样的步骤刷回去
- **小爱不能唤醒** → 记下来告诉我，这影响播报功能
- **浏览器打不开地址** → 确认 Mac 没睡、和音箱在同一个 WiFi、地址里的 IP 是最新的
- **其他** → 拍照发我
